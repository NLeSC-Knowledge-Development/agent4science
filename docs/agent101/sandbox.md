# Sandbox for agent

## Overview of agent sandbox:

distinguish two types of sandbox
sandbox is outside of an entire agent to provide secure env to use agent, e.g. a VM, microVM, docker sandbox, sandboxy
sandbox is inside of agent to execute code, run commands, use tools, and explore web. [Our focus]

overview of existing solution for the 2nd type of sandbox , e.g.

- https://aaif.io/projects/opensandbox
- https://github.com/containers/bubblewrap
- https://github.com/nolabs-ai/nono
- https://pydantic.dev/docs/monty
